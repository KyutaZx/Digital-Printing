### 4.1.2 Analisis Aplikasi Sejenis

Untuk mengukur keunggulan kompetitif dari antarmuka pelanggan (*Customer-facing features*) yang dibangun, analisis komparasi dilakukan terhadap aplikasi percetakan *Business-to-Consumer* (B2C) komersial yang sudah mapan di Indonesia, salah satunya adalah Uprint.id (https://uprint.id/).

Komparasi ini difokuskan secara murni pada fungsionalitas operasional yang dapat diakses langsung oleh pelanggan saat melakukan siklus pemesanan. Hasil perbandingan fitur layanan pelanggan antara Web-Based OMS Jaya Mandiri dengan platform publik tersebut dijabarkan pada Tabel 4.1 di bawah ini.

**Tabel 4.1** Perbandingan Fitur Pelanggan (*Customer*) Jaya Mandiri OMS dengan Uprint.id

| Fitur Pelanggan (*Customer-Facing*) | Jaya Mandiri OMS | Uprint.id (Platform Publik) |
| :--- | :---: | :---: |
| Eksplorasi Katalog Produk & Keranjang Belanja | ✔ | ✔ |
| Fasilitas Upload File Desain Mandiri | ✔ | ✔ |
| Validasi Resolusi Desain Otomatis (*AI Blur Detection*) | ✔ | ✖ *(Pengecekan manual oleh tim pre-press setelah pesanan dibayar)* |
| Pelacakan Status Pesanan (*Order Tracking*) | ✔ | ✔ |
| Riwayat Transaksi & Unduh Dokumen Invoice | ✔ | ✔ |

Berdasarkan tabel komparasi di atas, kedua sistem secara umum telah memfasilitasi kebutuhan dasar *e-commerce* percetakan seperti eksplorasi katalog, manajemen keranjang belanja, hingga pelacakan pesanan. Namun, OMS Jaya Mandiri memiliki keunggulan inovatif yang sangat signifikan pada tahapan pra-cetak (*pre-press*) melalui integrasi Kecerdasan Buatan (AI).

Pada platform konvensional komersial seperti Uprint.id, pelanggan memang dapat mengunggah file desain secara mandiri, namun pengecekan kelayakan resolusi gambar (apakah gambar pecah atau buram) umumnya baru dievaluasi secara manual oleh staf desainer setelah pelanggan menyelesaikan tahapan pembayaran. Alur kerja ini berpotensi memicu penundaan proses produksi (*bottleneck*) jika ternyata file yang dikirimkan tidak memenuhi standar cetak, sehingga staf harus menghubungi pelanggan kembali secara manual.

Sebaliknya, sistem OMS Jaya Mandiri secara proaktif mengotomatisasi tahapan ini menggunakan model AI (*blur/noise detection*) yang langsung mengevaluasi tingkat ketajaman file secara *real-time* sesaat setelah proses unggah (*upload*) berlangsung. Inovasi ini memberikan umpan balik (*feedback*) instan kepada pelanggan di detik yang sama, mempercepat beban kerja verifikasi di sisi staf operasional, dan secara krusial mencegah masuknya file berkualitas rendah ke antrean mesin cetak.
